# 抖店批量替换SKU

独立 Chrome MV3 侧栏插件，管理已有商品的规格、价格库存与 SKU 图。洗链接中的“新增规格”只在当前商品编辑页添加 SKU，不创建整条商品，也不填写标题或图文信息；规格导入沿用 Excel 智能识别，新增 SKU 的价格库存沿用现有写入方式。

价格库存替换可选择当前商品分组与筛选结果、按商品名称/商品 ID/商家编码查询后的结果，或当前商品编辑页。商品分组、状态页签和筛选条件以抖店商品管理页当前状态为准，插件会显示并锁定本次使用的页面链接。

“替换”的可修改模块支持“价格库存”和“SKU 图片”。每个模块旁都有独立的文件夹投放区，支持从资源管理器拖入文件夹或点击选择：价格库存目录需要包含 `规格.xlsx` 和 `规格价格表.xlsx`，也支持直接同时拖入这两份 Excel 文件；SKU 图片目录直接放图片即可，不再要求 `图文信息/SKU` 层级。投放后可用右侧的清除按钮移除该模块材料。`Thumbs.db`、`.DS_Store` 和 `desktop.ini` 等系统缓存文件会自动忽略。两项同时勾选时，插件在重建 SKU 后上传匹配图片；只勾选“SKU 图片”时，只替换当前 SKU 图片，不改价格库存。图片沿用原规则：文件名必须通过预检，已有图片本地替换、没有图片本地上传，无法匹配的规格跳过；替换页不自动发布。

在 `chrome://extensions` 启用开发者模式后，选择“加载已解压的扩展程序”，并选择此目录。插件只在 `https://fxg.jinritemai.com/*` 页面运行，不包含整商品新建或图文发布流程。
